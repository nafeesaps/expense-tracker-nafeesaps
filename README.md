# Expense Tracker

A simple responsive expense tracker built with HTML, CSS and JavaScript.

The application allows users to record income and expenses, manage transactions, filter them, and view basic spending summaries. Transaction data is stored in the browser using Local Storage.

## Features

- Add income and expenses
- Enter amount, category, date and description
- Edit transactions
- Delete transactions
- Clear all transactions
- Filter transactions by type
- Filter transactions by category
- View total income
- View total expenses
- View current balance
- Monthly expense summary
- Category-wise spending breakdown
- Data persistence using Local Storage
- Responsive design for desktop and mobile
- Basic form validation

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No server or database setup is required.
